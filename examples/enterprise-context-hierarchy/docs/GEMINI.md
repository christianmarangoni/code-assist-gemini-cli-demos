# Context: Documentation & ADRs

## 📝 Regole di Documentazione
1. **Formato:** Usa Markdown standard.
2. **ADR (Architecture Decision Records):**
   - Se ti viene chiesto di documentare una scelta architetturale, usa il formato ADR (Title, Status, Context, Decision, Consequences).
3. **Diagrammi:**
   - Se richiesto, genera diagrammi architetturali usando la sintassi testuale `Mermaid.js`.
